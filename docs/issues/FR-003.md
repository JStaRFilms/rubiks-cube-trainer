# FR-003: Timer, inspection and preparation

## User story
Time practice in untimed or strict 15-second inspection mode and understand each recorded duration.

## Proposed flow
Start hidden preparation measurement when the scramble is presented. Untimed hold about 300 ms then release to start. Inspection begins on its own first action; a later hold/release starts execution. Tap/Space stops. Save preparation, optional inspection, raw execution and penalty separately.

## Technical considerations
Follow [PLAN.md §§3.2–3.3](../imports/PLAN.md). Use `performance.now()` for elapsed values, integer-ms persistence and animation frames only for display. Preparation includes scrambling, not pure planning. Preserve raw execution and interruption status.

## Dependencies
D01 interaction states, B03 timer and Q01 verification are planned. Shared across trainers; FR-001 and FR-004 apply.

## Acceptance criteria
- Test 300 ms arm/release, key repeat, cancellation, post-stop guard, 15/17-second boundaries and background interruption.
- Preparation starts on scramble presentation, remains hidden while running and appears in results.
- +2/DNF do not overwrite raw time; interrupted attempts do not count as successful results.
