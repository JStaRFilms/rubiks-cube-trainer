# FR-008: F2L case and slot practice

## User story
Practice a canonical F2L pair in a chosen slot with execution or recognition controls.

## Proposed flow
Select case/family and FR-only or random slot, rotation hint, mode and optional personal algorithm. Show an isolated pair case with cross and all other pairs solved. Hide identity and algorithm during recognition until review.

## Technical considerations
Follow [PLAN.md §4.3](../imports/PLAN.md). The isolated context is deliberate, not arbitrary scrambled pieces. Canonical numbering excludes solved/duplicate angle variants. Test slot transforms.

## Dependencies
B07 verified library precedes B08; Q03 follows. Planned tasks, not present outputs. Requires FR-002/003/004/012/013.

## Acceptance criteria
- All 41 canonical cases and supported transforms have fixtures proving identity and preserved context.
- Recognition does not leak identity; hint visibility follows setting.
- Personal algorithms are validated against intended case.
- Statistics distinguish case, slot, hint, mode and inspection.
