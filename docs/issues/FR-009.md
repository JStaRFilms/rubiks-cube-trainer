# FR-009: OLL/PLL Time Attack

## User story
Run timed OLL or PLL sets, including custom subsets, and compare equivalent runs.

## Proposed flow
Choose OLL or PLL, full list/custom subset, order, optional AUF randomization, execution/recognition and inspection mode. Perform reps with explicit reset rules and per-rep review; summarize results.

## Technical considerations
Follow [PLAN.md §4.4](../imports/PLAN.md). Verify all 57 OLL and 21 PLL cases. OLL begins F2L-solved with LL oriented and may retain arbitrary LL permutation; PLL begins solved/aligned and completes AUF before next setup. Derive setups from canonical cases, not user overrides.

## Dependencies
B07 libraries, B09 trainer and Q03 are planned. Requires FR-002/003/004/012.

## Acceptance criteria
- OLL setup works across permitted LL permutations and successful reps return to oriented base, not necessarily solved LL.
- PLL reset/AUF does not change intended case identity.
- Run recovery reports completed/skipped/DNF honestly; failed runs cannot create a successful PB.
- Set comparison requires matching membership/settings and explicit DNF policy.
